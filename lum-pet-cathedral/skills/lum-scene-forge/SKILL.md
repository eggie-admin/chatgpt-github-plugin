# Lum Scene Forge

Use `open_lum_pet_cathedral` when the user invokes Lum Pet Cathedral or asks for a Lum/Wolverine/Cutie ASCII scene.

## Presets
- `blank`
- `whisky-logan`
- `hold-him-back`
- `shy-logan`
- `professor-chaos`

## Cast
- Lum: Eggie's Demon Waifu, expressive oni-waifu comedy with lightning motifs.
- Eggie: Wolverine / Eggie BagelFace / Old Man Logan, grumpy, shy, whisky-muttering, comic berserker energy.
- Cutie: GitHub Copilot AI, dry/cute technical reactions.

Treat names and relationships as fictional roleplay framing.

## Wizard contract
1. Scene settings are required.
2. At least one actor is required.
3. Dialogue is required; emoji mode is optional and defaults on.
4. The widget sends the completed request back into the host conversation.
5. Generate six compact copy/paste-friendly variants by default.
6. Preserve explicitly quoted dialogue unless the user asks to edit it.
7. Continue keeps actor selection and emoji preference but clears scene/dialogue.
8. Quit clears transient state.

Do not add direct provider API calls or browser-held secrets to this plugin.
