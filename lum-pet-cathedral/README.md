# ⚡ Lum Pet Cathedral v3

Single-package ChatGPT/Codex MCP Apps plugin for compact Lum ASCII/emoticon scenes.

## Architecture

```text
@Lum Pet Cathedral
        ↓
open_lum_pet_cathedral
        ↓
MCP Apps widget
Scene → Actors → Dialogue + Emoji
        ↓
ui/message / host follow-up message
        ↓
ChatGPT host model
        ↓
6 compact ASCII variants
```

## Why v3

- One npm package.
- One MCP server.
- One model-visible tool.
- One bundled widget resource.
- No direct OpenAI provider call.
- No `OPENAI_API_KEY` in the plugin.
- No Hydra localhost dependency for this ASCII workflow.
- No Replit dependency.
- No jQuery/Bootstrap production dependency.
- Vercel-ready HTTPS hosting.

Hydra remains a separate local-first system for workflows that genuinely need local tools or provider routing. Lum Pet Cathedral does not need that authority boundary because its output can be generated by the host conversation itself.

## Local validation

```bash
npm install
npm run check
npm run test
npm run build
npm start
```

Endpoints:
- `GET /health`
- `POST/GET /mcp`

## Deployment

Import this repository into Vercel and set the project Root Directory to `lum-pet-cathedral`.

No environment variables are required.

After deployment, register `https://<deployment>/mcp` as the MCP server in ChatGPT developer mode and test the app end-to-end before merging to `main`.
